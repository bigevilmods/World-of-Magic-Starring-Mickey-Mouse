Static Recompilation of World of Magic Starring Mickey Mouse - NES
Just put your .nes file in the same folder of the .exe generated.
The name of the .nes file must be like this : "World of Magic.nes".
Pre-requistes:
in order to compiled the executable file you need Microsft C++ compiler.

Working:
Save State
Up to 4K Resolution
32 bit colors
Controls: F2 - Open Menu F5 - Save game state F9 - Load Save state Space : action Enter = Start arrows = control
